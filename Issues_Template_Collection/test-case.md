This template provides a standardized format for creating and documenting test cases. It helps ensure consistent test execution, improves traceability, and verifies that application functionality meets the expected requirements.

## ✅ Review Checklist

Before marking the test case as complete, verify the following:

- [ ] Preconditions verified
- [ ] Test data prepared
- [ ] Test steps executed
- [ ] Expected result validated
- [ ] Actual result recorded
- [ ] Attachments added (if required)
- [ ] Test status updated
